# Busyboard Test

Приложение для управления заявками на поставку с онбординг-туром.

## Установка и запуск

```bash
npm install
npm start
```

Приложение будет доступно на `http://localhost:3000`

## Онбординг

4 шага Joyride, циклический. Закрыть — кнопка (крестик). После закрытия для перезапуска нужно перезагрузить страницу.
